# Installation

Install Tabloom from PyPI using Python 3.12 or newer:

```bash
pip install tabloom
```

This also installs the initial runtime dependencies, pandas and matplotlib.
The PyPI distribution and Python import names are both `tabloom`.

To install optional Jupyter kernel and widget support for the notebooks:

```bash
pip install "tabloom[example]"
```

For contributor tools, see
[CONTRIBUTING.md](https://github.com/michalszc/tabloom/blob/master/CONTRIBUTING.md).
The [basic usage example](../examples.md) verifies package import and version output.
