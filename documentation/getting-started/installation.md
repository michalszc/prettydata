# Installation

Install PrettyData from PyPI using Python 3.12 or newer:

```bash
pip install prettydata
```

This also installs the initial runtime dependencies, pandas and matplotlib.
The PyPI distribution and Python import names are both `prettydata`.

To install optional Jupyter kernel and widget support for the notebooks:

```bash
pip install "prettydata[example]"
```

For contributor tools, see
[CONTRIBUTING.md](https://github.com/michalszc/prettydata/blob/master/CONTRIBUTING.md).
The [basic usage example](../examples.md) verifies package import and version output.
