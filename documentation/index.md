# Tabloom

Tabloom is being developed to make visually appealing tables, charts, and
reports convenient to create in Python, with sensible defaults and minimal setup.

!!! note "v0.0.0 — Repository Foundation"

    This milestone establishes packaging and development infrastructure only.
    The package is importable, but there are no table, chart, data-import, export,
    styling, or PDF APIs yet.

Planned work includes pandas integration, rows and records, dataset imports,
matplotlib charts, attractive tables, exporting, and combining visuals into PDF
reports. These capabilities are not currently available.
